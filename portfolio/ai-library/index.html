06 — What is usable in this ChatGPT session?

  • Available now: code and architecture analysis, drafting implementations and tests, research, and authorized GitHub reading/writing through the connected app.
  • Connector-dependent: direct operations in Figma and other services only when the relevant app is connected and authorized.
  • Adaptable: methodologies can be turned into instructions, prompts, checklists and project templates.
  • External runtime: native Codex/Claude Code skills, arbitrary MCP servers, shell scripts and autonomous agent loops need their intended runtime and explicit setup.

None of the listed upstream collections is represented as installed merely by appearing in this catalogue.

07 — Security before adoption

  1. Verify maintainer, repository history, license and exact version/commit.
  2. Read all instructions and referenced files; inspect scripts and dependencies.
  3. Check network access, telemetry, filesystem writes, secrets and environment-variable access.
  4. Start in a disposable branch and test environment with least privilege.
  5. Require human approval for destructive actions, production changes and deployment.

Security status: unreviewed until a specific version and its executable files have been inspected. A curated index is not a security certification.
