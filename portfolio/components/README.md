# Portfolio component boundaries

The static site keeps the runtime entrypoint in `portfolio/index.html`, while these source boundaries document the intended component model:

- hero.html
- stack.html
- work.html
- cases.html
- engineering.html
- experience.html
- contact.html
- navigation.html
- footer.html

Shared styling lives in `fullstack-design.css` plus the systems/editorial layer in `editorial.css`; interaction logic remains in `fullstack.js`.
