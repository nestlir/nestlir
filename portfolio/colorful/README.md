# Portfolio A — Colorful

The original expressive visual direction: dopamine landing, candy palette, editorial typography, photography, stickers, anime/pop-culture references and cinematic project popups.

## Purpose

This version emphasizes visual/frontend/product work and is intentionally more playful than the Full-stack version.

## Features

- RU / EN language switch;
- project filters;
- project popup with image, role, stack and repository;
- light/dark theme;
- responsive layout;
- animated marquee and decorative stickers;
- keyboard Escape support for popup;
- reduced-motion fallback.
