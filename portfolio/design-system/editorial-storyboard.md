# Editorial Storyboard — Issue 01

The issue uses eight numbered pages. Desktop shows a cover or a two-page spread; mobile reveals each page individually in the same reading order.

| Page | Section | Purpose | Main visual |
|---:|---|---|---|
| 01 | Cover | Establish identity, role and issue tone | Approved fashion-illustration cover art |
| 02 | Contents / Letter | Explain the author's approach and guide the reader | Editorial contents list + short author note |
| 03 | Tools of the Trade | Show technology groups without fake skill scores | Typeset stack groups and technical labels |
| 04 | DataVac | Explain team-project context and the owner's limited frontend contribution | Custom ledger / product workflow illustration |
| 05 | Furniture Store | Show an AI-assisted experiment honestly, including the author's brief and direction | Custom commerce / interface illustration |
| 06 | Study Index | Present educational assignments as learning work, not client work | Numbered archive of five assignments |
| 07 | How I Work | Explain interface, API, data, testing and delivery thinking | Custom architecture / flow diagram |
| 08 | Correspondence | Give clear contact and profile links | Character portrait accent + contact details |

## Page-turn model
- Page 01 opens as a single full-bleed cover.
- Desktop groups pages 02–03, 04–05 and 06–07 as spreads.
- Page 08 closes as a single page.
- Mobile displays page 01–08 one at a time.
- Contents links jump to the first page of a section and update the reader position.
- Folios are printed on the page; the reader counter communicates current position.
