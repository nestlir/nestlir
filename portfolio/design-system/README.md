# Atelier Narrative — Magazine Design System

Design source for the fullscreen editorial portfolio. The live implementation is under `../` and uses the assets in `../assets/magazine/`.

## Direction
A personal, collectible digital magazine for Anastasia's full-stack / frontend engineering work. The visual language combines mid-century fashion-editorial illustration, printed-paper tactility, restrained botanical ornament and precise technical diagrams. It is not a fashion portfolio: engineering work, contribution boundaries and project evidence remain the primary content.
