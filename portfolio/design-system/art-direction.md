# Art Direction — Atelier Narrative

## Creative premise
A full-screen digital issue designed like a collectible ladies' illustrated magazine, reinterpreted as a Fullstack Developer portfolio. The reference contributes its fashion-illustration craft, ornate costume construction, clean graphic contour, olive/cream color harmony and editorial typesetting. It does not supply its character, exact layout, title, copy or proprietary motifs.

## Visual DNA
- Warm ivory, slightly aged uncoated paper.
- Deep olive-charcoal reader surround.
- Dark wine / near-black ink.
- Muted sage and antique gold.
- Small, decisive persimmon-orange highlights.
- Oversized high-contrast editorial serif mastheads.
- Compact mono metadata, issue numbers, folios and captions.
- Restrained decorative botanical engraving.
- Detailed custom fashion illustration as the emotional identity; technical diagrams and project evidence as the content identity.

## Illustration treatment
Use defined silhouettes, confident variable-weight linework, designed hair masses, layered garment construction, carefully placed embroidery, two-to-four-value cel/gouache shading, small colored-pencil accents and controlled printed-paper grain. Preserve the user's individual face proportions; do not substitute generic anime or doll features. The character is a visual guide through the issue, not a substitute for project evidence.

## Composition
- Cover: one strong fashion-portrait composition, editorial masthead, issue label, concise engineering positioning and short cover lines.
- Inner pages: two-page desktop spreads with deliberate asymmetry, page folios, small running headers and one dominant focal point per page.
- Mobile: one page at a time; typography, image crop and reading sequence reflow rather than scale down a desktop spread.
- Project spreads: one page for problem / role / decisions; one page for visual proof / system diagram / repository link.

## Avoid
Generic SaaS cards, neon gradients, glassmorphism, dashboard stock imagery, random Japanese text or cultural motifs, fake client logos, invented performance metrics, decorative noise, excessive AI micro-patterns, illegible overlaid text and over-polished vector contours.

## Content hierarchy
1. Real project / learning context and contribution boundary.
2. Engineering problem and decisions.
3. Stack and supporting visuals.
4. Editorial personality and illustration.
The portfolio must read as a software engineer's body of work, not an illustration showcase.
