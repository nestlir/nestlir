# UI Kit — Magazine Reader

## Controls
- Primary action: filled deep-olive rectangular button, ivory label, small arrow.
- Secondary action: transparent paper button, fine ink border.
- Icon button: square outline with large simple arrow glyph; accessible label.
- TOC link: large serif section title, italic olive index, mono folio.
- Technology token: thin hairline border, mono label, no pill radius.
- Project label: compact uppercase mono eyebrow with optional orange "TEAM", "AI-ASSISTED" or "STUDY" marker.
- Inline link: underline / bottom rule; external links show ↗.
- Progress indicator: eight small segments, current page filled orange.
- Mobile menu: paper panel with large serif nav labels.

## Page furniture
Running header, section label, issue number, page folio, thin rule, center gutter, optional orange marker and a small botanical ornament.

## State rules
- Focus: 2–3px orange outline with visible offset.
- Hover: subtle underline or 2px lift only; never color-only.
- Active: solid ink / paper inversion or orange edge.
- Disabled: reduced contrast and disabled semantics.
- Loading: reserve space; do not shift the spread.
- Error: inline explanatory text adjacent to the control.
- Success: concise confirmation plus next action.

## Forms
If a contact form is used, labels remain visible; required fields are announced; errors are connected with aria-describedby; confirmation is polite-live. A mailto fallback must remain available.

## Icons
Use the bespoke outlined set in `../assets/magazine/icons/`. Icons supplement text and never replace labels.
